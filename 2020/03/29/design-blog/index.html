博客与主题的设置和日常操作

发表于 2020-03-29 更新于 2026-10-14 分类于 教程
记录本站搭建时的几个常用设置：添加「关于」页面、开启本地搜索、显示阅读进度，以及用 more 标记截断首页摘要。

本文记录本站搭建过程中的几个常用设置：添加「关于」页面、开启文章搜索、显示阅读进度，以及首页摘要的截断方式。

添加「关于」页面

由于使用的是 NexT 主题，两步就够了：

  1. 通过 Hexo 新建索引页：

    hexo new page "about"

  2. 在主题配置 _config.next.yml 的 menu 中加上 about 一行（本站已开启）：

    menu:
  home: / || fa fa-home
  about: /about/ || fa fa-user
  tags: /tags/ || fa fa-tags
  archives: /archives/ || fa fa-archive

在首页添加其他页面，照猫画虎就行。

主题配置统一写在站点根目录的 _config.next.yml，不要改 themes/next/_config.yml，否则升级主题时会被覆盖。

开启文章搜索

首先安装插件，在博客根目录执行：

npm install hexo-generator-searchdb --save

然后在站点配置文件 _config.yml 中添加：

search:
  path: search.xml
  field: post
  content: true
  format: html
  limit: 10000

最后在主题配置文件 _config.next.yml 中找到 local_search，确认启用，其他项按需调整：

local_search:
  enable: true
  # 每篇文章最多显示的匹配条数，-1 表示不限
  top_n_per_article: 1
  unescape: false
  preload: false

侧边栏就会出现搜索框。

注意：安装 hexo-generator-searchdb 时若报错，请根据提示修复相关依赖，否则搜索框可能显示异常。

显示阅读进度

在主题配置文件 _config.next.yml 中开启（本站当前未启用，需要时加上即可）：

reading_progress:
  enable: true
  # 可选值：top | bottom
  position: top
  color: "#37c6c0"
  height: 2px

首页摘要截断

在文章中单独一行插入 <!-- more -->，首页只显示它之前的内容，并出现「阅读全文」按钮：

<!-- more -->

正文里直接写这一行即可，不需要转义。
